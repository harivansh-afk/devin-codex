# devin-codex

Use the Codex TUI with Devin inference.

Requirements:

- installed Codex (tested: 0.155.1)
- Devin CLI on PATH.

```sh
nix profile add git+https://git.harivan.sh/harivansh-afk/devin-codex
devin-codex
```
